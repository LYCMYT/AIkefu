## 2. Clean-room 原则

### 允许

- 参考公开产品交互和截图理解需求
- 使用用户提供的静态逆向总结确认产品边界
- 重新设计独立的数据模型和实现
- 使用 MockDouyinAdapter
- 未来接入官方开放 API / SDK 或书面授权接口

### 禁止

- 复制原程序源码
- 复制私有 GraphQL、Webpack 模块、DOM 注入脚本
- 导入 Cookie / Token / 浏览器缓存
- 绕过验证码、MFA、安全策略或反自动化机制
- 把参考产品品牌、图标、用户数据直接用于公开作品
- 像素级复刻参考产品
- 声称已接入未实现的平台
