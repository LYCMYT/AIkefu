# 阶段 UI-2：知识管理

参考图：`docs/aikefu-frontend-codex-ui-pack-v1/references/02-knowledge.png`

## 目标
重构知识管理页，突出知识运营、导入结果和冲突治理，减少大段说明。

## 页面结构
1. 标题 + 一行副标题。
2. Tabs：正式知识、候选知识、冲突记录、学习任务。
3. 筛选：店铺、类型、状态、搜索。
4. 指标：正式知识、候选知识、冲突条目；只显示真实接口数据。
5. 主表：标题、类型、来源、范围、状态、更新时间、操作。
6. 右侧/抽屉导入面板：Excel/CSV 文件、进度、可导入/重复/冲突/错误、下载结果、重新导入。
7. 新建、编辑、启用/停用、Soft Delete、重新索引保持现有逻辑。

## 交互原则
- 解释内容放 Tooltip、Drawer 或帮助入口，不占主视图。
- 冲突与错误使用明确状态色，但整体克制。
- 空状态提供“导入知识”或“新建知识”操作。

## 验收
- 表格导入、预览、确认、异常结果、知识状态与索引状态均可用。
- 不硬编码统计值。
- 页面在 1440×900 下层级清晰。
