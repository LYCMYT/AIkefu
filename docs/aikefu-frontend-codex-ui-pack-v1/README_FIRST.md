# AIKefu 前端重构 Codex 执行包

## 使用方式
1. 将本目录整体复制到项目仓库 `docs/ui-redesign/`。
2. 在 Codex 中打开 `LYCMYT/AIkefu` 仓库，新建分支：`feat/frontend-redesign-v1`。
3. 每个阶段开启一个新的 Codex 会话，不要一次执行全部页面。
4. 第一轮发送 `00_MASTER_GUARD.md`，随后发送当前阶段文件。
5. 每个阶段完成后，人工查看页面截图、运行测试并提交 Git，再开始下一阶段。

## 推荐推理强度
- UI 样式、组件拆分、普通表格：Low
- 跨页面状态、WebSocket、业务状态联调：Medium
- 默认不要使用 High；只有明确复杂竞态问题时临时使用。

## 核心原则
- 参考图只规定视觉语言与信息层级，不是数据真相。
- 绝不硬编码参考图中的人数、金额、头像、指标或订单。
- 所有内容来自现有 API、WebSocket、Seed 或真实空状态。
- 不改后端契约、数据库、AI流程和可靠性机制。
