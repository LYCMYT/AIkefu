# Codex 全局执行指令：前端重构安全边界

你正在 `LYCMYT/AIkefu` 仓库中工作。目标是在不改变现有业务行为、后端契约、数据结构与可靠性机制的前提下，将前端重构成简洁、高级、可直接作为求职作品展示的企业级 AI 客服 SaaS。

## 必须遵守
1. 只修改前端及前端测试；除非构建被现有后端类型错误阻塞，不修改 `apps/api`、Prisma、消息状态机、RAG、Workflow Runtime、SendGuard、Outbox 或 Recovery 行为。
2. 保留现有路由、API 参数、WebSocket 事件和功能；不得用静态假数据替代真实接口。
3. 参考本目录 `references/`（仓库路径 `docs/aikefu-frontend-codex-ui-pack-v1/references/`）的图片，仅学习布局、密度、层级、留白和视觉语言；不得复制其中虚构数据、品牌、人物头像或文本。
4. 删除“纯说明式大段文字”和无意义占位卡，改成简短标题、状态、Tooltip、空状态和可操作 CTA。
5. 先拆分超大文件，再按页面改造。目标：`App.tsx` 只保留路由/Provider/AppShell；API 按领域拆分；样式按 token、layout、feature 拆分。
6. 优先复用现有依赖；新增依赖必须是前端必要依赖，且先检查 package.json。不要引入重型 UI 框架替换整个项目。
7. 所有页面必须包含 Loading、Empty、Error、Disabled、Permission/Unavailable 状态；禁止只做 Happy Path。
8. 保持键盘可用、焦点可见、对比度合理；1440×900 无横向溢出，Workflow 画布除外。
9. 不输出长篇分析。开始时计划最多 8 条；完成时报告最多 12 行，不粘贴完整代码或 diff。
10. 每阶段只做当前页面，运行相关 typecheck/test/build，保存截图到 `artifacts/ui/`，然后停止等待确认。

## 视觉系统
- 侧栏：深海军蓝 `#0B1428`，激活态靛紫 `#4F46E5`。
- 主背景：`#F6F8FC`；内容卡：白色；边框：`#E7EAF1`。
- 主文本：`#111827`；次文本：`#667085`；成功：`#12B76A`；警告：`#F79009`；危险：`#F04438`。
- 圆角：卡片 12px，控件 8–10px；阴影轻微，不使用厚重玻璃、强渐变或高噪装饰。
- 采用 8px 间距系统；标题 24/32、区块标题 18/28、正文 14/22、辅助 12/18。
- 图标统一线性风格，优先现有图标库。

## 验收底线
- 真实 API 与 WebSocket 功能不回归。
- 不出现参考图中的假数字。
- 页面不是静态图片复刻，所有按钮、筛选、标签、状态与数据均连接现有逻辑。
- 相关测试、typecheck、build 通过。
