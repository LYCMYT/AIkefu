# 阶段 UI-4：数据概览

参考图：`docs/aikefu-frontend-codex-ui-pack-v1/references/04-dashboard.png`

## 目标
将数据看板改为克制、可信、少说明的运营概览。所有数字必须来自现有真实 Demo 数据或明确的空状态。

## 页面内容
1. 日期范围与店铺筛选。
2. 核心指标：在线店铺、今日会话、AI自动回复率、人工接管率；根据现有接口映射，不存在则不展示。
3. 会话趋势图：总会话与人工接管会话。
4. 高频问题分布或意图分布。
5. 热门咨询 TOP5。
6. AI Usage：调用数、Token、平均每会话消耗、Fallback/失败（仅现有数据）。

## 原则
- 不为了填满页面创造假指标。
- 无数据时显示精简空状态和数据来源说明。
- 图表 Tooltip、Legend、单位统一；不使用 3D 图表或复杂装饰。

## 验收
- 筛选变化能够刷新数据。
- 图表可读、响应式、无假数据。
- Loading/Empty/Error 状态完整。
