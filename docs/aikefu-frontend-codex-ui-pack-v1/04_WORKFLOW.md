# 阶段 UI-3：AI 工作流

参考图：`docs/aikefu-frontend-codex-ui-pack-v1/references/03-workflow.png`

## 目标
重构 `/workflows` 为真正可用的三栏可视化编排界面，不改变现有 Workflow Runtime 与版本发布逻辑。

## 布局
- 左：工作流搜索、列表、草稿/已发布状态。
- 中：画布，工具栏含选择、拖动、缩放、适应画布、自动排列。
- 右：节点库与选中节点配置。
- 顶部：新增、保存草稿、发布配置。

## 节点
使用现有支持的节点类型和状态；卡片要简洁，显示名称、类别、关键配置和错误状态。不要发明后端不存在的节点。

## 必须保留
- 草稿/发布版本区分。
- 连线、节点配置、运行日志、Human Approval。
- 失败、等待审批、STALE、已完成状态。

## 验收
- 现有工作流可载入、编辑、保存、发布和查看运行记录。
- 画布是交互实现，不是静态 SVG。
- 1440×900 无整体横向溢出，画布自身可平移缩放。
